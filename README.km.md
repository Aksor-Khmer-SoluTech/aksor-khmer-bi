# aksor-khmer-bi

**កម្មវិធីបង្កើតឯកសារជាភាសាខ្មែរ បើកជាសាធារណៈ និងអាចដំឡើងដំណើរការដោយខ្លួនឯង** —
បង្កាន់ដៃ វិក្កយបត្រ លិខិតជូនដំណឹង សញ្ញាបត្រ ឬអ្វីផ្សេងទៀតតាមតម្រូវការរបស់អ្នក។
បំពេញទម្រង់គំរូ (template) តែម្តង រួចទទួលបានលទ្ធផលជា **PDF, PNG, DOCX, ឬ XLSX**
ដោយមានការចុះបន្ទាត់ និងតម្រឹមអត្ថបទខ្មែរបានត្រឹមត្រូវ — រួមទាំងអត្ថបទខ្មែរដែលគ្មានចន្លោះ
រវាងពាក្យ ដែលកម្មវិធីបង្ហាញគេហទំព័រ/PDF ភាគច្រើនធ្វើខុសដោយស្វ័យប្រវត្តិ (មើល
[`docs/khmer-line-breaking.md`](docs/khmer-line-breaking.md)) ។

[Read this in English →](README.md)

*"អក្សរ" សំដៅលើអក្សរ/តួអក្សរខ្មែរ — ឈ្មោះនេះចង្អុលទៅបញ្ហាដ៏ពិបាកបំផុតដែល
គម្រោងនេះដោះស្រាយ គឺការបង្ហាញអក្សរខ្មែរឱ្យបានត្រឹមត្រូវ។*

សាងសង់ និងផ្ទៀងផ្ទាត់ជាបណ្តើរៗ៖ រាល់ការអះអាងនៅក្នុងឯកសារខាងក្រោមត្រូវបានត្រួតពិនិត្យ
ជាមួយលទ្ធផលបង្ហាញជាក់ស្តែង មិនមែនសន្មតទេ។ សូមមើល
[`docs/why-aksor-khmer-bi.md`](docs/why-aksor-khmer-bi.md) សម្រាប់ហេតុផលពេញលេញ
ក្នុងការប្រើប្រាស់ — និងបញ្ជីស្មោះត្រង់នៃអ្វីដែលគម្រោងនេះមិនមែន (វាមិនមែនជាវេទិកា
វិភាគទិន្នន័យ/BI ទេ គ្មានការតភ្ជាប់ទិន្នន័យ (data connectors) ដោយផ្ទាល់ទេ — មើលឯកសារ
នោះសម្រាប់ព័ត៌មានលម្អិត) ។

## ហេតុអ្វីមានម៉ាស៊ីនបង្ហាញលទ្ធផលពីរ

សង្ខេបខ្លីៗ៖ WeasyPrint មិនអាចបង្កើត `.docx` បានទេ ហើយទាំងពីរម៉ាស៊ីនមិនអាចបង្កើត
`.xlsx` បានទេ — ដូច្នេះទម្រង់ភាគច្រើនមានមាគ៌តែមួយប៉ុណ្ណោះ។ ជម្រើសពិតប្រាកដមានតែ
PDF/PNG ដែល LibreOffice អាចតម្រឹមអត្ថបទខ្មែរបានត្រឹមត្រូវដោយផ្ទាល់ ចំណែក
WeasyPrint ត្រូវការជំហានញែកពាក្យមុន ប៉ុន្តែស្រាលជាង។ ពន្យល់លម្អិតពេញលេញ៖
[`docs/architecture.md`](docs/architecture.md)។

## ចាប់ផ្តើមប្រើប្រាស់

```bash
docker compose up --build
# បើក http://localhost:8000/docs (ឯកសារយោង API) ឬ http://localhost:8080 (កម្មវិធីគ្រប់គ្រងទម្រង់គំរូ)
```

សូមមើល [`docs/getting-started.md`](docs/getting-started.md) សម្រាប់ការណែនាំ
ពេញលេញ (ទាំងមាគ៌ា Docker និង local venv បង្ហាញលទ្ធផលគំរូដែលភ្ជាប់មកជាមួយ
រួចចុះឈ្មោះ និងបង្ហាញលទ្ធផលពីទម្រង់គំរូផ្ទាល់ខ្លួនរបស់អ្នក)។

ឬហៅកម្មវិធីដោយផ្ទាល់ដោយមិនចាំបាច់ឆ្លងកាត់ API៖

```python
from doc_engine import render

data = {"taxpayer_name": "សុខ សុភា", ...}  # មើល api/app/models.py សម្រាប់រូបរាងពេញលេញ
pdf_bytes = render(data, "pdf")                       # ម៉ាស៊ីន LibreOffice (លំនាំដើម)
pdf_bytes = render(data, "pdf", backend="weasyprint")  # ម៉ាស៊ីន WeasyPrint
docx_bytes = render(data, "docx")
xlsx_bytes = render(data, "xlsx")

# ឬបង្ហាញលទ្ធផលពីទម្រង់គំរូផ្ទាល់ខ្លួនរបស់អ្នក ជំនួសទម្រង់ដែលភ្ជាប់មកជាមួយ៖
pdf_bytes = render(my_data, "pdf", template_path="my_template.docx")
```
